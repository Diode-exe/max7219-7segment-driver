# max7219-7segment-driver

Driver for the 7 segment Maxwell MAX7219 7 segment display

## Functions

- ```clear()``` clears the display

- ```text()``` write to the buffer

- ```show()``` show the buffer on the display

- ```brightness()``` changes the brightness

- ```scroll()``` scrolls a long string across the display

- ```power()``` toggle display power without clearing the buffer

- ```brightness_fade_out()``` fade screen out

- ```brightness_fade_in()``` fade screen in

- ```set_num()``` set the display to show a number

- ```blink()``` makes the display blink a specified number of times

- ```set_bar()``` turn on the bottom segments for a specified length

- ```rotate_segments()``` creating a spinning wheel animation on specified char

- ```set_char()``` sets a specific character at the given buffer index
